# Item icons

Put icon images in this folder and list them in `manifest.json`, mapping each item's id to its file name:

```json
{
  "ar_acr": "ar_acr.png",
  "skill_drone_striker": "skill_drone_striker.webp"
}
```

Item ids are the `id` values in the `data/` files. PNG, WebP, JPG and SVG all work.
Items without an entry simply show no icon.
